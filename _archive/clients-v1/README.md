# Clients — логотипы, версия 1 (архив от 11.11.2026)

Стена из 16 логотипов: сетка 4×4, на телефонах 2×8. Логотипы серые,
закрашены через CSS-маску. Строки появляются по очереди при прокрутке.

Папка начинается с «_», поэтому GitHub Pages её не публикует.

## Файлы

| Файл           | Откуда взят                                          | Куда вернуть |
|----------------|------------------------------------------------------|--------------|
| `clients.html` | `index_work.html`, строки 67–98                      | Между бегущей строкой (`.ticker`) и `<section class="efficiency" id="approach">` |
| `clients.css`  | `style.css`, строки 281–450 + мобильные 1892–1910    | Десктоп: перед `.efficiency`. Мобильные: внутрь блока `@media (max-width: 639px)` (начинается со строки 1744), после правил `.ticker`. Обёртку `@media` из архива не копировать |
| `clients.js`   | `index_work.html`, строки 1139–1161                  | В блок GSAP после триггеров `.insight-anim`, перед «Grouped reveals» |

Номера строк указаны на момент архивации.

## Что ещё связано с секцией

- **Логотипы:** `assets/logos-clients/*.svg`. Пока архив может понадобиться, папку не удалять.
- **Общая анимация** в `index_work.html` (строка 774): `'[data-reveal]:not(.client)'`.
  Исключение `:not(.client)` нужно, чтобы ячейки не анимировались дважды. Без старой
  секции оно ничего не делает и не мешает.
- **Ссылки на якорь `#clients`:** меню (строка 37) и футер (строка 496). Новая секция
  должна сохранить `id="clients"`, иначе ссылки перестанут работать.
- **Светлая тема:** правило `body.theme-light .clients` (есть в `clients.css`).
